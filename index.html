💡 สรุปสูตรอนุพันธ์พื้นฐาน (Cheat Sheet)

1. กฎกำลัง (Power Rule)
d/dx (x^n) = n · x^(n-1)
2. อนุพันธ์ของค่าคงที่
d/dx (c) = 0
3. ฟังก์ชันตรีโกณมิติ
d/dx (sin x) = cos x ,   d/dx (cos x) = -sin x
4. ฟังก์ชันเอ็กซ์โพเนนเชียล
d/dx (e^x) = e^x
5. กฎลูกโซ่ (Chain Rule)
d/dx (f(g(x))) = f'(g(x)) · g'(x)
